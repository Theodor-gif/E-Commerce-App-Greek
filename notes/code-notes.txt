2. Βασική δομή αρχείου HTML5
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="stylesheet" href="style.css" />
    <title>Το όνομα της ιστοσελίδας</title>
  </head>
  <body>
    <!-- Εδώ γράφουμε το περιεχόμενο της ιστοσελίδας -->
  </body>
</html>
• <head>: περιέχει πληροφορίες για την ιστοσελίδα προς τον browser (metadata), όπως την κωδικοποίηση, τον τίτλο και το αρχείο CSS.
• <link>: συνδέει το αρχείο CSS. Στο href γράφουμε τη διαδρομή προς το αρχείο.
• <body>: περιέχει ό,τι εμφανίζεται στη σελίδα.

3. Σημασιολογικές ετικέτες (semantic tags)
Οι σημασιολογικές ετικέτες βοηθούν τον browser και τις μηχανές αναζήτησης να κατανοούν τη δομή και το περιεχόμενο της σελίδας. Βελτιώνουν επίσης την προσβασιμότητα, γιατί διευκολύνουν τα άτομα με προβλήματα όρασης που χρησιμοποιούν προγράμματα ανάγνωσης οθόνης.
• <header>: η επικεφαλίδα της σελίδας ή μιας ενότητας.
• <nav>: το μενού πλοήγησης, με συνδέσμους προς τις υπόλοιπες σελίδες.
• <main>: το κύριο περιεχόμενο της σελίδας.
• <section>: χωρίζει το περιεχόμενο σε θεματικές ενότητες.
• <article>: αυτόνομο κομμάτι περιεχομένου, όπως μια κάρτα προϊόντος ή ένα άρθρο. Συχνά βρίσκεται μέσα σε <section>.
• <aside>: δευτερεύον περιεχόμενο, συνήθως στο πλάι του κυρίως περιεχομένου.
• <footer>: το τέλος της σελίδας, με πληροφορίες δικαιωμάτων, μικρότερο μενού και στοιχεία επικοινωνίας.

////////////////////////////////////////////////////////////////////////////////////////////////////

4. Μη σημασιολογικές ετικέτες
Τις χρησιμοποιούμε όταν καμία σημασιολογική ετικέτα δεν ταιριάζει και θέλουμε απλώς να ομαδοποιήσουμε στοιχεία.
• <div>: στοιχείο block, παίρνει όλο το πλάτος της γραμμής.
• <span>: στοιχείο inline, παίρνει μόνο το πλάτος που χρειάζεται.

////////////////////////////////////////////////////////////////////////////////////////////////////

5. Βασικές ετικέτες
Οι ετικέτες που χρειαζόμαστε για την πρώτη μας απλή σελίδα:
• <h1> έως <h6>: τίτλοι, από τον πιο σημαντικό (h1) στον λιγότερο σημαντικό (h6).
• <p>: παράγραφος.
• <a>: υπερσύνδεσμος.
• <button>: κουμπί.
• <ul>, <ol>, <li>: λίστες χωρίς και με αρίθμηση, και τα στοιχεία τους.
• <dl>, <dt>, <dd>: λίστα περιγραφής, με όρο και ορισμό.
• <img>: εικόνα.
• <form>, <label>, <input>: φόρμα, ετικέτα πεδίου και πεδίο εισαγωγής.

7. Βασικοί επιλογείς (selectors)
Οι επιλογείς χρησιμοποιούνται στη CSS3 και στη JavaScript για να διαλέγουμε τα στοιχεία που θέλουμε.
p { }      /* επιλογέας στοιχείου: όλες οι παράγραφοι */
.card { }  /* επιλογέας class */
#head { }  /* επιλογέας id (μοναδικός στη σελίδα) */
* { }      /* καθολικός επιλογέας: όλα τα στοιχεία */
