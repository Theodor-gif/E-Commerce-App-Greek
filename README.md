# Fashion Store | E-Commerce με HTML5 και CSS3

Ένα απλό project e-commerce ιστοσελίδας, φτιαγμένο με HTML5 και CSS3. Δημιουργήθηκε για να εξασκήσω όσα έχω μάθει και για να βοηθήσει όσους κάνουν τα πρώτα τους βήματα στη δημιουργία ιστοσελίδων.

## Περιγραφή

Το project περιλαμβάνει δύο σελίδες:

- **Αρχική σελίδα**: banner, πλοήγηση και 3 ενότητες για την μόδα.
- **Σελίδα προϊόντων**: πλέγμα προϊόντων 3 x 3 με τίτλο και τιμή.

Και οι δύο σελίδες έχουν κοινό footer με newsletter, μενού, βοήθεια και πλοήγηση.

## Τεχνολογίες

- HTML5 (σημασιολογικές ετικέτες)
- CSS3

## Σημείωση

Η ιστοσελίδα δεν είναι προσαρμοσμένη σε όλες τις αναλύσεις οθόνης. Επικεντρώνεται στη σωστή χρήση των ετικετών HTML και στη δημιουργία μιας απλής αρχικής σελίδας.

## Πώς να το τρέξεις τοπικά

1. Κατέβασε ή κάνε clone το project.
2. Άνοιξε το φάκελο στο VS Code.
3. Εγκατάστησε την επέκταση **Live Server**.
4. Κάνε δεξί κλικ στο `index.html` και διάλεξε **Open with Live Server**.
5. Η σελίδα ανοίγει στη διεύθυνση `http://127.0.0.1:5500/`.
